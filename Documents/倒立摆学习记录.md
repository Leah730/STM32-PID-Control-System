# 倒立摆实现

为了防止倒立摆失控，在最开始一定要先写好倒立摆启动和停止的控制框架：
- 通过按键，手动控制倒立摆程序的启动和停止。
- 程序启动时，一旦判断倒立摆倒了，那么程序要立刻自动停止，以免失控。
- 实现倒立摆程序的启停，通过标志位变量来实现。

## 如何判断倒立摆倒了

用AD模块读取角度传感器。

- 如果摆杆在中心角度附近一定范围内，认为倒立摆没有倒，处于可调控范围。
- 如果摆杆偏离中心角度太远，甚至说摆杆处于水平状态了，那这时再怎么调节，摆杆都不可能立起来了，这时要自动关闭PID程序。
- 所以要定义一个中心角度值，和一个可调控的角度范围区间，比如500。

内环角度环的任务是保持摆杆稳定倒立；
外环位置环的任务是保持横杆位置固定在一个地方。

角度换的输出值直接给电机PWM；
调控周期确定：40ms->20ms->10ms->5ms->1ms（没什么提升）,所以选择5ms。

## 内环PID调参（定位置PD）

**遇到的问题**

无论怎么调节Kp，Kd，摆杆怎么都无法稳定转起来。

**解决办法**

发现是硬件的问题，因为与摆杆连接的顶丝没有拧紧，摆杆与下面的竖杆应该始终在同一条直线上。

**遇到的问题**

无论给的初始力是朝哪个方向的，摆杆一直朝右转。

**解决办法**

说明是设置的中心角度不准，如果一直向右转，那说明中心角度要改小。

Kp 0.1（太慢了，转不起来）->0.2（可以）->0.3（稍微抖动）->0.4（大抖动）
Kd 0.1->0.2->0.3->0.4

PD最终还会倒下，因为，当摆杆在中心角度附近时，误差很小，P项调控力度也很小，这导致最后一点误差消除不了，这样，实际角度就不是准确无误的和中心角度重合，那摆杆位置就会一致跑，最终因不稳定而倒下去。所以可以加一点点的Ki=0.01，这样摆杆就可以长时间保持倒立，但是摆杆的位置会到处乱跑（越来越快），因为还没有对位置进行闭环控制，现在内环调试完成。

内环的好处，直接影响倒立摆能不能立起来，而外环的好处，只是影响位置固定的快不快，准不准。改变内环目标角度可以让位置向左或向右片，这时外环控制位置的基础。外环的输出值控制内环的目标角度，在中心角度的基础上加一点或减少一点（这个限度就是OutMax和OutMin，限度越大，内环的目标角度改变幅度就会很大，导致横杆移动过快，+-100是合适的，来控制横杆的位置左移或者右移。

## 外环调参

先设置Kp=0，Ki=0，Kd=0.

第一步，测试PID极性对不对。Kp=0.1，启动，向左移，Out为负，对应内环的目标值减小，摆杆就会像左倾斜，意味着位置会进一步向左移动，越向左移动，摆杆就越向左倾斜......，这说明是正反馈，会疯狂左转，极性反了。简单地把位置环的Out值取负值就可以，注意Act会有65535溢出。小车后退时Speed<0,Location += Speed，无符号减法下溢，直接变成65535.比如，uint16_t Location = 5; Location += (-10); 无符号运算：5-10=65531，所以必须改成int16_t.

Kp=0.2，发现来回震荡，同时摆动幅度越来越大，这就是典型的阻尼不足的现象。调大Kd，加上阻尼，这个摆动幅度就会逐渐削减，最终位置会稳定下来，实测这个Kd得拧的非常大才行，Kd改成0-9调节，加到2，摆动几乎没有了，用手施加一下扰动，位置最终可以回到0位置。

最终选定Kp=0.4，Kd=4.0是合适的。

如果位置最终吻合地很好，可以不加入I项。

内环的中心角度设置不准确，会导致外环PD控制器产生稳态误差，且内环中心角度偏向哪个方向，外环稳态误差就会偏向哪个方向。内环角度换加入I项，没啥事，应该也有超调，但左右偏离的角度不会太大，所以超调也不明显，而定位置控制的实际值会离目标值比较远，解决办法有
- 调节目标角度
- 加入I项，积分分离

**转着转着摆杆又不稳定了**

还是顶丝松了，这次是下面的。很多时候都是顶丝的问题（紧一紧）。

把中心角度值设置为2060，就减少了误差。

void TIM1_UP_IRQHandler(void)
{
	static uint16_t Count1,Count2;
	
	if (TIM_GetITStatus(TIM1, TIM_IT_Update) == SET)
	{
		Key_Tick();
		
		Angle = AD_GetValue();
		Speed = Encoder_Get();
		//也可以在Encoder_Get函数中直接返回TIM_GetCounter，因为计数器CNT的值，本身就是位置
		//Location += Encoder_Get();
		Location += Speed;
		
		if(!(Angle > CENTER_ANGLE - CENTER_RANGE
			&&Angle < CENTER_ANGLE + CENTER_RANGE))
		{
			RunState = 0;
		}
		
		if(RunState)
		{
			Count1++;
			if(Count1 >= 5)
			{
				Count1 = 0;
				
				AnglePID.Actual = Angle;
				PID_Update(&AnglePID);
				Motor_SetPWM(AnglePID.Out);
			}
			Count2++;
			if(Count2 >= 50)
			{
				Count2 = 0;
				
				LocationPID.Actual = Location;
				PID_Update(&LocationPID);
				AnglePID.Target = CENTER_ANGLE - LocationPID.Out;
			}
		}else
		{
			Motor_SetPWM(0);
		}
		
		TIM_ClearITPendingBit(TIM1, TIM_IT_Update);
	}
}

## 倒立摆自动起摆

**如何使摆杆从下垂状态摆动到上面的中心区间里**

共振摆动，施加力的频率和摆杆来回摆动的频率保持对应。就像荡秋千，需要在秋千荡到最高处时给它施加一个短暂的推力。

**如果确定摆杆处于最高点**

以固定周期T，采样3次角度传感器的值。
- 首先判断，它处于左侧区间还是右侧区间
- 如果是左侧，中间一次角度值，大于第一次和第三次的角度值说明处于最高点
- 如果是右侧，中间一次角度值，小于第一次和第三次的角度值说明处于最高点

**如何施加瞬时驱动力**

- 如果摆杆处于右侧区间且处于最高点位置，则横杆需要向左施加顺时驱动力
- 如果摆杆处于左侧区间且处于最高点位置，则横杆需要向右施加顺时驱动力
- 如果摆杆进入中心区间，则启摆结束，开始执行PID控制程序

**判断AD引脚是否悬空**

2次AD转换，也就是同一个ADC引脚，改变两次连接状态。

第一次模拟输入A，连接外部模拟信号，问：外面有没有电压？

第二次下拉输入B，内部把引脚下拉到GND，问：如果我强行给你0V，你会不会跟着变成0？

- 如果A时，AD值不为0，B时，AD值为0，则AD引脚悬空，处于盲区；
- 如果B时，AD值不为0，则没悬空，以模拟输入的值作为角度值即可。

```c
void TIM1_UP_IRQHandler(void)
{
	static uint16_t Count0,Count1,Count2,CountTime;
	static uint16_t Angle0,Angle1,Angle2;
	
	if (TIM_GetITStatus(TIM1, TIM_IT_Update) == SET)
	{
		Key_Tick();
		
		Angle = AD_GetValue();
		Speed = Encoder_Get();
		//也可以在Encoder_Get函数中直接返回TIM_GetCounter，因为计数器CNT的值，本身就是位置
		//Location += Encoder_Get();
		Location += Speed;
		
		if(RunState==0)
		{
			Motor_SetPWM(0);
		}else if(RunState==1)
		{
			Count0++;
			if(Count0>=40)
			{
				Count0=0;
				
				Angle2 = Angle1;
				Angle1 = Angle0;
				Angle0 = Angle;
				
				if(Angle0 > CENTER_ANGLE + CENTER_RANGE
					&& Angle1 > CENTER_ANGLE + CENTER_RANGE
					&& Angle2 > CENTER_ANGLE +CENTER_RANGE
				&& Angle1 < Angle0
				&& Angle1 < Angle2)
				{
					RunState = 21;
				}
				
				if(Angle0 < CENTER_ANGLE - CENTER_RANGE
					&& Angle1 < CENTER_ANGLE - CENTER_RANGE
					&& Angle2 < CENTER_ANGLE -CENTER_RANGE
				&& Angle1 > Angle0
				&& Angle1 > Angle2)
				{
					RunState = 31;
				}
				
				if(Angle0 > CENTER_ANGLE - CENTER_RANGE
					&& Angle0 < CENTER_ANGLE + CENTER_RANGE
					&& Angle1 > CENTER_ANGLE - CENTER_RANGE
					&& Angle1 < CENTER_ANGLE + CENTER_RANGE
					&& Angle2 > CENTER_ANGLE - CENTER_RANGE
					&& Angle2 < CENTER_ANGLE + CENTER_RANGE)
				{
					//规定起摆成功的位置就是0，避免急切回到0位置，摇晃不稳定
					Location = 0;
					//避免误差累积
					AnglePID.ErrorInt = 0;
					LocationPID.ErrorInt = 0;
					RunState = 4;
				}
			}	
		}else if(RunState==21)
		{
			Motor_SetPWM(START_PWM);
			CountTime = START_TIME;
			RunState = 22;
		}else if(RunState==22)
		{
			CountTime--;
			if(CountTime==0)
			{
				RunState = 23;
			}
		}else if(RunState==23)
		{
			Motor_SetPWM(-START_PWM);
			CountTime = START_TIME;
			RunState = 24;
		}else if(RunState==24)
		{
			CountTime--;
			if(CountTime==0)
			{
				Motor_SetPWM(0);
				RunState = 1;
			}
		}else if(RunState==31)
		{
			Motor_SetPWM(-START_PWM);
			CountTime = START_TIME;
			RunState = 32;
		}else if(RunState==32)
		{
			CountTime--;
			if(CountTime==0)
			{
				RunState = 33;
			}
		}else if(RunState==33)
		{
			Motor_SetPWM(START_PWM);
			CountTime = START_TIME;
			RunState = 34;
		}else if(RunState==34)
		{
			CountTime--;
			if(CountTime==0)
			{
				Motor_SetPWM(0);
				RunState = 1;
			}
		}else if(RunState==4)
		{
			if(!(Angle > CENTER_ANGLE - CENTER_RANGE
				&&Angle < CENTER_ANGLE + CENTER_RANGE))
			{
				RunState = 0;
			}
			
			Count1++;
			if(Count1 >= 5)
			{
				Count1 = 0;
				
				AnglePID.Actual = Angle;
				PID_Update(&AnglePID);
				Motor_SetPWM(AnglePID.Out);
			}
			Count2++;
			if(Count2 >= 50)
			{
				Count2 = 0;
				
				LocationPID.Actual = Location;
				PID_Update(&LocationPID);
				AnglePID.Target = CENTER_ANGLE - LocationPID.Out;
			}
		}
		
		TIM_ClearITPendingBit(TIM1, TIM_IT_Update);
	}
}
```
