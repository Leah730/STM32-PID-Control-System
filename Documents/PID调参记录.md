# PID调参记录

## 调控周期的确定

编码器读取周期肯定不能长于PID调控周期，如果时间长了，那么PID调控时，编码器测量的实际速度还没有刷新，PID调控这么快，根本没有意义；编码器读取周期最好不要短于PID调控周期，因为编码器测量快，PID调控慢，那么编码器中间的一些值，PID根本没有用到，又因为编码器读取越快，其测速精度就越低，所以编码器读取周期没有必要短于PID调控周期。所以编码器的读取周期和PID调控周期保持一致是最好的。

40ms就不错，编码器测速和电机驱动都是顺时针为正，逆时针为负，极性一致，是没有问题的，PID调控是负反馈。若极性不一致，PID调控就会变为正反馈，出现一点点误差，PID调控会使得误差无限增大，电机不受控制，疯狂旋转。负反馈调控，会使得误差减小，正反馈调控，会使得误差增大。

每隔40ms读取一次编码器，值为32，意思是速度为32个边沿/40ms。

系数K的取值数量级：输出范围/输入范围

Kp = RP_GetValue(1) / 4095.0 * 2 （防止丢失小数）范围给0-2

## 位置式PID定速控制调参

Actual = Encoder_Get_Filtered();

Kp=1.2 （存在稳态误差）Ki = 0.2 (可以跟踪）
通过实验连接的串口图可以看出，越靠近目标值，实际值是放缓的，所以是不需要加入D项的。

位置式PID定速控制中修改参数时，Ki会先设置为0，这时始终存在稳态误差，会使得ErrorInt一直累加，达到一个很大的值。之后一旦Ki不等于0了，积分项就会猛地输出很大的调控力，这其实是积分饱和问题。

## PID计算
```c
Out = Kp*Error0+Ki*ErrorInt+Kd*(Error0-Error1);
```
## 增量式PID定速控制调参

经过测试，Kp=1.1，ki=0.3，Kd=0是合适的，Kp再高就有点抖动了。调控周期10ms效果就很完美。

```c
Out += Kp*(Error0-Error1)+Ki*Error0+Kd*(Error0-2*Error1+Error2);
```

Ki ->0.1，过冲抖动->0.02->0.06
Kp 0.6
Kd 0.35->0.4
所以Kp=0.6,Ki=0.06,Kd=0.4是合适的。

**位置式PID和增量式PID的本质区别**

Out = Kp*Error0+Ki*ErrorInt+Kd*(Error0-Error1);
Out += Kp*(Error0-Error1)+Ki*Error0+Kd*(Error0-2*Error1+Error2);

位置式PID直接计算当前应该输出多少PWM，Out=Kp*Error0+Ki*积分+Kd*微分，误差越小，输出越小。

增量式PID不直接算输出，它算这一次PWM要增加多少或减少多少。

**为什么说它依赖积分项**

如果没有积分项，电机不是无线加速的，有很多阻力：摩擦力、负载、电机反电动势、空气阻力会导致产生的电磁力，也就是向前动力刚好抵消阻力，所以最后误差不再变化，PWM不再增加，电机速度也不再变化，就产生了稳态误差。积分项关注误差存在了多久，负责消除长期误差。

**为什么位置式PID没那么依赖积分**

因为位置式每一次都重新计算，误差一直存在，它一直保持输出，但是增量式它只看要不要输出，如果误差不变，那么P项失效。

简单类比：位置式PID项踩油门，速度低多少，踩多少油门，一直有输出。增量式PID项调油门旋钮，问要把油门再拧多少。P说不需要调整了，只有积分说：虽然没变化，但是一直差着阻力，还要继续加。

速度控制-非常需要积分：因为负载变化会产生恒定误差，积分慢慢增加PWM，恢复。

增量式速度PID，Ki一般不能省，否则，负载变化后，速度会停在目标附近，但是有偏差。

**总结**

增量式PID的P项只负责“改变输出”，不负责“保持输出”。当误差不再变化时，P项贡献趋近于0；只有积分项能够继续累积误差，使输出继续调整，因此增量式PID通常更依赖积分项来消除稳态误差。

速度环-PI为主；位置环-PD为主；双环控制-速度内环PI+位置外环P/PD。

## 双环PID定速定位置控制调参

内环：实际速度对目标速度的跟踪。

先调Kp，逐步加大Kp，直到实际值出现抖动，然后到适当减少Kp，让抖动消失。
Kp 0.1->0.25->0.3->0.5（抖动比较厉害了）->0.4（还有超调）->0.35->0.3->0.5->0.6->0.8->0.9->1.0->1.1（最大值抖动会更厉害一些）->1.2（这个一般值时效果没1.1好）
1.1对比0.35，还是1.1效果更好一些

**稳态误差**

直接加Ki 0.1（稳态误差消除比较慢）->0.3（正好）->0.5（还是很好，没有超调）->0.7（抖动竟然更少了）->0.9（速度越大，抖动越少）->1.1（依然没有超调，抖动更少）->1.3（依然没有超调，一般时候抖动都很少）->1.5（最大时抖动不明显，一般时抖动更多一些）->1.4（最大时更优秀了，一般时抖动也不错），还是1.1把，看一般时的绿线更清晰一些，抖动少。

所以最终选择Kp=1.1，Ki=1.1，Kd=0，比较合适。

外环位置环一般用PD控制器，所以先从小到大调节Kp。Kp 0.1（拧目标位置，速度可以，但是有超调，这些超调可以通过D项消除）。

Kd 0.1->0.3->0.5（震荡了，慢且有超调）->0.4->0.3->0.25（有超调），还是0.35吧，慢慢调吧。

所以最后选择Kp=0.1，Kd=0.35，不过快了还是有超调了。
